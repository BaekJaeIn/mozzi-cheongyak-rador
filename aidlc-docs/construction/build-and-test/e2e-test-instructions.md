# E2E 테스트 안내

## 실행

```bash
# 빌드 안내의 로컬 환경 변수(로컬 Supabase·임시 암호화 키·임시 VAPID)를 넣고
npm run build && npx next start -p 3123          # 별도 창
E2E_BASE_URL=http://localhost:3123 npm run e2e   # 또는 그냥 npm run e2e (빌드·서버를 Playwright가 띄움)
```

- 기기: **Android**(Galaxy S9+, Chromium), **iPhone**(iPhone 13, WebKit). 접근성은 axe(WCAG 2.1 AA).
- 테스트 공고·구독 확인은 `e2e/helpers.ts`가 **로컬 Supabase일 때만** 한다. 운영 주소면 해당 테스트는 건너뛴다.
- CI `db-and-e2e`가 main push마다 같은 구성으로 실행한다(임시 키를 매번 새로 만듦).

## 알아 둘 점

- 테스트 브라우저는 실제 푸시 서비스에 구독할 수 없어 권한·구독 API를 가짜로 바꾼다. **실제 알림 도착은 실기기**로 확인한다(아래).
- 서비스워커가 있는 페이지는 WebKit에서 `page.route` 가로채기를 거치지 않는다 → 인터넷 끊김을 흉내 내는 테스트 2개만 `serviceWorkers: "block"`.

| 기기 | 확인 |

| 어머니 iPhone (홈 화면 앱) | 설치 → 알림 켜기 → 시험 알림 도착 → 누르면 설정 화면 |

## 설계 메모 (질문 아님)

- **"새 항목을 입력했는지"는 기기에만 기록한다** (`mz.updates`). 서버는 모른다. 기기마다 한 번씩 안내하면 되고, 모두 지우기에서 함께 지운다
- **옮겨 온 프로필은 새 항목이 "아직"이다.** 기기에 저장된 프로필이 버전 1이었으면 처음 읽을 때 "통장 명의·다른 지역 아직 입력 안 함"으로 기록한다. 옮기기 결과(통장 있음 → 명의 "나", 없음 → "모름")는 U2 그대로 쓰고, 짧은 입력 화면에서 다시 묻는다
- 혼자 사는 가구도 통장 "없음"이었으면 "모름"으로 바뀌었으니 짧은 입력 화면에서 통장을 다시 묻는다 (명의 질문 대신 있음/없음)
- 짧은 입력 화면은 **확인 화면 없이** 마지막 화면의 [저장]으로 끝나고 피드로 간다. 저장은 지금처럼 기기 저장 → 서버 보내기(ProfileSync)
- 설정에서 "청약통장"·"관심 지역" 그룹을 고쳐 저장해도 그 항목은 입력한 것으로 본다
- 기존에 고른 3기 신도시 지구는 그대로 둔다(C2-D6). 처음 입력하는 사람은 지금처럼 6개 모두 선택된 채로 시작한다(US-07)
- 처음 설치하는 사람(프로필 없음)에게는 안내 카드·띠를 띄우지 않고, 안내 버전을 본 것으로 기록한다(FR-C2-18)

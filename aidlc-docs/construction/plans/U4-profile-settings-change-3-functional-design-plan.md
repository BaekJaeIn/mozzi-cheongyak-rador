1. **가구 종류 화면**: 처음 입력 첫 화면. [노부부·어르신] / [신혼부부·예비신혼부부] 큰 보기 2개 + 한 줄 설명
2. **신혼 마법사**: 가구 종류가 신혼이면 질문이 달라진다 (혼인·자녀, 생애최초, 부부 각자 통장·소득)
3. **설정**: "가구 종류" 줄, 바꾸면 그 종류 질문을 처음부터(지금 값으로 채움). 신혼 가구용 설정 그룹
4. **마법사 답·초안 형식**: 새 답 키, 초안 버전 2 → 3 옮기기, 답 ↔ 프로필 v3 변환
5. **부모님 기기 그대로**: 업데이트 안내 버전을 올리지 않는다, 노부부 화면 순서·문구·저장 결과 그대로
6. PBT 속성 추가

## 설계 메모 (질문 아님)

- **부모님 기기**: 프로필이 이미 있으면 가구 종류 화면을 띄우지 않는다(옮기기 결과 노부부). "새로 바뀐 점" 안내 버전도 올리지 않는다 — 묻는 것이 없다(FR-C3-2, US-26)
- **노부부 마법사는 지금 그대로**: 가구 종류 화면이 맨 앞에 하나 늘어나는 것 말고는 화면·순서·문구·저장 값이 같다. 노부부 답으로 만든 프로필은 `householdKind = "senior"`, `newlywed = null`
- **신혼 가구는 부부**(BR-U2-D3): "가구 구성" 화면을 묻지 않고 `householdType = "couple"`, 가구원 수 = 2 + 자녀 수(태아 포함). 배우자 생년월일은 지금처럼 [잘 모르겠어요] 가능
- **신혼 가구는 생년월일 범위가 다르다**: 본인 1960~(올해 − 19), 처음 보이는 해 1995. 노부부는 지금 그대로(1930~1975, 1960)
- **신혼 가구는 "복지 대상" 화면을 묻지 않는다**: 복지 조건은 어르신 대상 공급유형에만 있고, 신혼 가구에는 그 유형의 신청 방법이 없다(U2 routesFor). `welfare = null`
- **생애최초 질문**: "지금 집이 있음"이면 "집을 가진 적 없음" 화면은 건너뛰고 `neverOwnedHome = false`
- **혼자 사는 노부부 가구가 신혼으로 바꾸면** 배우자 생년월일부터 다시 묻는다(가구 구성은 부부로 바뀜)
- **신혼 → 노부부로 바꾸면** 신혼 정보(`newlywed`, 배우자 월소득)는 저장할 때 지운다. 노부부 마법사 전체를 지금 값으로 채워 다시 묻는다
- 금액 입력·단위 실수 확인·[잘 모르겠어요]·확인 화면·기기 저장 → 서버 보내기는 지금 규칙 그대로(FR-C3-5)

# 모찌네 청약 알리미 — 페르소나

> 근거: requirements.md §2, story-generation-plan.md Part B-2
> 실제 가족 정보(생년월일·소득·자산 등)는 적지 않고, 사용 특성만 일반화해 기술한다.

---

## P1. 아버지: "알림 오면 확인하는" 실사용자

| 항목 | 내용 |
|---|---|
| 나이대 | 만 60세 이상 |
| 가구 | 부부 2인 가구, 이 기기에서 "본인"은 아버지, "배우자"는 어머니 |
| 기기 | 본인 휴대폰 (Android 또는 iPhone) |
| 디지털 숙련도 | 카카오톡·유튜브·문자는 익숙함. 앱 설치, 권한 설정, 브라우저 메뉴는 낯섦 |
| 신체 특성 | 노안으로 작은 글씨를 읽기 어려움. 작은 버튼을 잘못 누르는 일이 잦음 |
| 목표 | 3기 신도시에서 **두 부부가 실제로 신청할 수 있는** 공고가 나오면 놓치지 않고 알고 싶다 |
| 불편 | 청약홈·LH·SH·GH를 일일이 들어가 보기 어렵다. 공고문이 길고 용어("특별공급", "무순위")가 어렵다. 자격이 되는지 스스로 판단하기 어렵다 |
| 사용 패턴 | 평소에는 앱을 열지 않음 → **하루 1번 알림이 오면** 눌러서 확인. 처음 설정할 때만 정보를 길게 입력 |
| 성공의 모습 | 자격 되는 공고를 하나도 놓치지 않고, 접수 기간 안에 원문을 확인한다 |

## P2. 어머니: "따로 설치해서 같이 챙기는" 실사용자

| 항목 | 내용 |
|---|---|
| 나이대 | 만 60세 이상 |
| 가구 | P1과 같은 가구, 이 기기에서 "본인"은 어머니, "배우자"는 아버지 |
| 기기 | **본인 휴대폰에 따로 설치** (Android 또는 iPhone). P1 기기와 연결되지 않음 |
| 디지털 숙련도 | P1과 비슷하거나 조금 낮음. 숫자·금액 입력을 특히 부담스러워함 |
| 목표 | 아버지와 별개로 본인 휴대폰에서도 알림을 받아 **같이 챙기고** 싶다. 알림 받는 시간은 본인 생활에 맞추고 싶다 |
| 불편 | 같은 가구 정보를 한 번 더 입력해야 함. 금액 단위(원/만원)가 헷갈림 |
| 사용 패턴 | 알림 위주. 관심 공고를 저장해 두고 아버지와 이야기할 때 다시 봄 |
| 성공의 모습 | 아버지와 **같은 가구 정보를 넣으면 같은 공고 목록**을 본다. 입력 실수 없이 설정을 마친다 |

## P3. 나: 예비신혼부부 (변경 요청 3)

| 항목 | 내용 |
|---|---|
| 누구 | 앱을 만든 자녀. 결혼을 앞둔 예비신혼부부, 맞벌이 예정 |
| 관심 | 경기 안양·군포·의왕, 서울. 신혼부부·생애최초 특별공급, 신혼희망타운, 신혼부부용 임대 |
| 목표 | 부모님과 **같은 앱**에서 **우리 가구 조건**에 맞는 공고만 받고, 관심 공고는 **마감 전에 알림**을 받는다 |
| 불편 | 기존 청약레이더(로그인)와 부모님 앱(로그인 없음)을 따로 관리해야 함. 예비신혼·맞벌이 조건이 공고마다 달라 헷갈림 |
| 사용 패턴 | 작은 글씨, 피드·상세를 자주 보고 관심 공고를 많이 별표 |
| 성공의 모습 | 내 휴대폰에 설치 → 가구 종류 "신혼·예비신혼" → 입력 → 내 조건에 맞는 공고와 이유. 부모님 휴대폰은 아무것도 바뀌지 않음 |

## 페르소나 ↔ 스토리 매핑

두 분 모두 같은 앱을 같은 방식으로 쓰므로 대부분의 스토리가 공통이다. P2에 특히 중요한 인수 기준은 스토리 안에 **[P2]**로 표시했다.

| 에픽 | 스토리 | P1 아버지 | P2 어머니 |
|---|---|:-:|:-:|
| E1 시작하기 | US-01 ~ US-03 | ● | ● |
| E2 내 정보 | US-04 ~ US-08 | ● | ●(금액 입력·재입력 부담 **[P2]**) |
| E3 공고 받기 | US-09 ~ US-11 | ● | ●(알림 시각 개별 설정 **[P2]**) |
| E4 공고 보기 | US-12 ~ US-17 | ● | ●(같은 정보 → 같은 결과 **[P2]**) |
| E5 관리 | US-18 ~ US-20 | ● | ● |
| 변경 3 신혼 가구 | US-22 ~ US-26 | 바뀌지 않음(회귀 없음, US-26) | 바뀌지 않음 |

P3(나)는 공통 스토리(US-01~US-20)도 모두 쓰고, 가구 종류만 다르다(US-22~US-25).

# 모찌네 청약 알리미 — 사용자 스토리

> 근거: requirements.md (D1~D20, FR-1~11, NFR-1~7), personas.md, story-generation-plan.md Part B-2
> 형식: "**~로서** ~하고 싶다, **~하기 위해**" + 체크리스트 인수 기준
> 사용자: P1 아버지, P2 어머니 (이하 "사용자"는 둘 다를 뜻함)
> 우선 원칙: **놓치지 않기**. 판정이 애매하면 숨기지 않고 "확인 필요"로 보여준다 (Q6=A)

---

## 공통 인수 기준 (모든 화면 스토리에 적용)

- [ ] 일반 모드 본문 글씨 16px 이상, 쉬운 모드는 약 1.25배 이상 (NFR-1.1)
- [ ] 누를 수 있는 요소는 최소 48×48px (NFR-1.2)
- [ ] 글자와 배경의 명도 대비 WCAG AA 이상 (NFR-1.2)
- [ ] 전문 용어 옆에 쉬운 말 풀이를 함께 쓴다 (NFR-1.3, FR-3.2)
- [ ] 오류가 나면 "무엇을 하면 되는지"를 한 문장으로 안내한다 (NFR-1.5)
- [ ] 화면 하단에 피드 / 관심 공고 / 설정으로 가는 큰 메뉴가 있다

## E1. 시작하기

### US-01 홈 화면에 앱 설치하기
**사용자로서**, 휴대폰 홈 화면에 앱 아이콘을 만들고 싶다, **알림을 받고 앱을 쉽게 다시 열기 위해.**
- 관련: FR-11.1, D15
- 인수 기준
  - [ ] Android(Chrome/삼성인터넷)에서는 "홈 화면에 설치" 버튼을 누르면 설치 창이 뜬다
  - [ ] iPhone(Safari)에서는 "공유 → 홈 화면에 추가" 순서를 **그림과 함께 단계별로** 안내한다
  - [ ] iPhone에서 홈 화면 앱이 아닌 Safari로 열었으면 "알림을 받으려면 홈 화면에 추가가 필요합니다"를 안내한다
  - [ ] 이미 설치된 상태로 열면 설치 안내를 다시 보여주지 않는다
  - [ ] 설치 후 아이콘 이름은 "모찌네 청약 알리미"(또는 홈 화면에 맞게 줄인 이름)로 보인다

### US-02 처음 실행할 때 안내받기
**사용자로서**, 처음 앱을 열었을 때 무엇부터 해야 하는지 알고 싶다, **헤매지 않고 설정을 마치기 위해.**
- 관련: FR-7.4
- 인수 기준
  - [ ] 프로필이 없으면 피드 대신 "내 정보를 넣으면 맞는 공고만 골라 드려요" 안내와 **[시작하기]** 버튼 하나만 보인다
  - [ ] 앱이 하는 일을 3줄 이내로 설명한다 (3기 신도시 공고 수집 → 자격 확인 → 하루 1번 알림)
  - [ ] [시작하기]를 누르면 입력 마법사(US-04)로 이동한다

### US-03 알림 허용하기
**사용자로서**, 새 공고 알림을 허용하고 싶다, **앱을 열지 않아도 새 공고를 알기 위해.**
- 관련: FR-11.2, D14
- 인수 기준
  - [ ] 마법사 마지막 단계(또는 설정)에서 "알림 받기" 버튼을 누를 때만 휴대폰의 알림 권한 창을 띄운다 (앱을 열자마자 묻지 않음)
  - [ ] 권한 창을 띄우기 전에 "하루 1번, 새 공고가 있을 때만 알려 드려요"를 먼저 보여준다
  - [ ] 허용하면 "알림이 켜졌어요"를 보여주고, 구독 정보를 이 기기(device_id)에 연결해 서버에 저장한다
  - [ ] 거부했으면 휴대폰 설정에서 다시 켜는 방법을 안내하고, 앱의 다른 기능은 그대로 쓸 수 있다
  - [ ] **[P2]** 어머니 기기에서 허용하면 어머니 기기로만 알림이 간다 (아버지 기기와 독립)

## E2. 내 정보

### US-04 기본·거주 정보 입력하기
**사용자로서**, 생년월일, 배우자 생년월일, 세대 구성, 사는 곳을 한 단계씩 입력하고 싶다, **나이·거주 조건을 확인받기 위해.**
- 관련: FR-4.1, FR-4.2(기본·거주), D13
- 인수 기준
  - [ ] 한 화면에 1~2개 항목만 묻고, 화면 위에 진행 표시(예: 2/7)가 있다
  - [ ] 모든 단계에 크게 [이전] / [다음] 버튼이 있다
  - [ ] 생년월일은 큰 숫자 선택(년·월·일)으로 입력하고, 입력 후 "만 OO세"를 바로 보여준다
  - [ ] 거주지는 시도 → 시군구 순서로 목록에서 고른다 (직접 타이핑 없음)
  - [ ] 거주 기간은 "1년 미만 / 1~2년 / …" 같은 선택형 또는 년 단위 숫자로 입력한다
  - [ ] **[P2]** "본인"과 "배우자"가 이 휴대폰 사용자 기준이라는 것을 문구로 알려 준다 (예: "이 휴대폰을 쓰시는 분의 생년월일")
  - [ ] 중간에 앱을 닫아도 입력한 단계까지는 기기에 남아 있다

### US-05 주택·청약통장 정보 입력하기
**사용자로서**, 집이 있는지, 청약통장이 있는지를 쉬운 질문으로 답하고 싶다, **무주택·통장 조건을 확인받기 위해.**
- 관련: FR-4.2(주택·청약통장)
- 인수 기준
  - [ ] "지금 집을 가지고 계신가요?"처럼 **예/아니오 질문**으로 시작하고, 답에 따라 필요한 질문만 이어서 묻는다
  - [ ] 무주택 기간, 보유 주택 수는 숫자 선택으로 입력한다
  - [ ] 청약통장이 "없음"이면 통장 관련 질문을 건너뛴다
  - [ ] 통장 종류는 이름과 쉬운 설명을 함께 보여준다 (예: "주택청약종합저축: 요즘 가장 많이 쓰는 통장")
  - [ ] 모르는 항목은 **[잘 모르겠어요]**로 넘어갈 수 있고, 그 항목은 비워 둔다 (→ 판정에서 "확인 필요", US-12)

### US-06 소득·자산 금액 입력하기
**사용자로서**, 월평균 소득, 총자산, 자동차 가액을 입력하고 싶다, **임대주택 소득·자산 기준을 정확히 확인받기 위해.**
- 관련: FR-4.2(소득·자산), D8, D12, NFR-2.3
- 인수 기준
  - [ ] 금액은 **만원 단위**로 입력하고, 입력하는 동안 "월 350만원"처럼 한글 금액을 크게 함께 보여준다
  - [ ] **[P2]** 단위 실수를 막는다: 일반적인 범위를 크게 벗어나면(예: 월 소득 10억원 이상) "입력하신 금액이 맞나요?"를 한 번 더 묻는다
  - [ ] 각 항목에 무엇을 넣는지 한 줄 설명이 있다 (예: "부부 두 분의 소득을 합친 월 평균")
  - [ ] **[잘 모르겠어요]**로 비워 둘 수 있다 (→ 소득·자산 조건은 "확인 필요")
  - [ ] "이 정보는 자격 확인에만 쓰이고, 암호화해서 저장해요"를 화면에 보여준다

### US-07 관심 지구·선호 조건 고르기
**사용자로서**, 관심 있는 3기 신도시와 원하는 집 조건을 고르고 싶다, **관심 없는 공고 알림을 받지 않기 위해.**
- 관련: FR-4.2(선호), FR-10.2, D5
- 인수 기준
  - [ ] 6개 지구(남양주 왕숙, 하남 교산, 고양 창릉, 부천 대장, 인천 계양, 광명 시흥)가 **큰 체크 카드**로 보이고, 처음에는 모두 선택되어 있다
  - [ ] 지구를 하나도 고르지 않으면 [다음]을 누를 수 없고 "한 곳 이상 골라 주세요"를 안내한다
  - [ ] 희망 전용면적은 "작게(~40㎡, 약 12평) / 보통(40~60㎡, 약 12~18평) / 넓게(60㎡~, 약 18평~)"처럼 **평 환산**과 함께 고른다 (여러 개 선택 가능)
  - [ ] 분양/임대 선호(분양 / 임대 / 둘 다), 저층 선호(예/상관없음)를 고른다
  - [ ] 선호 조건(면적·분양/임대·저층)은 **정렬 순서에만** 영향을 주고 공고를 숨기지 않는다. 숨기는 기준은 관심 지구와 자격 판정뿐이다 (놓치지 않기 원칙)

### US-08 입력 내용 확인하고 저장하기
**사용자로서**, 입력한 내용을 한 번에 확인하고 저장하고 싶다, **잘못 넣은 것을 바로 고치기 위해.**
- 관련: FR-4.3, D11, D12
- 인수 기준
  - [ ] 마지막에 모든 입력값을 그룹별로 큰 글씨로 보여주고, 그룹마다 [고치기] 버튼이 있다
  - [ ] [저장]을 누르면 기기에 저장하고 서버에 동기화한 뒤 "저장했어요"를 보여준다
  - [ ] 서버 저장에 실패해도 기기에는 저장되고, "인터넷 연결을 확인해 주세요. 다음에 앱을 열 때 다시 보낼게요"를 안내하며, 다음 실행 때 자동으로 다시 보낸다
  - [ ] 저장 후 알림 허용(US-03) 단계로 이어지고, 그다음 피드(US-12)로 이동한다
  - [ ] 비워 둔 항목이 있으면 "비워 둔 항목은 '확인 필요'로 표시돼요"를 안내한다

## E3. 공고 받기

### US-09 알림 시각 정하고 켜고 끄기
**사용자로서**, 알림 받을 시각을 고르고 알림을 켜고 끌 수 있으면 좋겠다, **내 생활에 맞는 시간에만 알림을 받기 위해.**
- 관련: FR-4.2(알림), FR-10.3, FR-11.3, D16
- 인수 기준
  - [ ] 알림 시각은 **0시~23시 중 1시간 단위**로 고르고, "오전 9시"처럼 오전/오후 표기로 보여준다
  - [ ] 기본값은 **오전 9시(KST)**다 (A1)
  - [ ] 알림 켜기/끄기 스위치가 크게 있다. 끄면 서버에서 이 기기로 보내는 알림을 멈춘다
  - [ ] 바꾸면 다음 알림부터 바로 반영된다
  - [ ] **[P2]** 어머니 기기와 아버지 기기는 알림 시각을 각자 따로 정한다

### US-10 하루 1번 새 공고 알림 받기
**사용자로서**, 정한 시각에 "새 공고 N건" 알림을 받고 싶다, **앱을 열지 않아도 새 공고가 나온 것을 알기 위해.**
- 관련: FR-11.3, FR-11.5, FR-5, FR-2, NFR-3.2, D9, D16
- 인수 기준
  - [ ] 정한 시각(KST, 정각 기준)에 지난 알림 이후 **새로 들어온** 공고 중 **관심 지구 + 판정 "충족" 또는 "확인 필요"** 공고 수를 알려 준다
  - [ ] 알림 문구 예: "새 공고 3건이 있어요 (자격 충족 2 · 확인 필요 1)"
  - [ ] 해당 공고가 0건이면 알림을 보내지 않는다
  - [ ] 같은 공고는 한 기기에 **두 번 세지 않는다** (발송을 다시 실행해도 중복 알림 없음)
  - [ ] 판정 "미충족" 공고는 알림 수에 넣지 않는다
  - [ ] 판정 기준과 결과는 피드(US-12)와 **똑같다** (알림은 3건인데 피드에는 2건 같은 불일치 없음)
  - [ ] 알림을 끈 기기(US-09)나 구독이 만료된 기기에는 보내지 않는다

### US-11 알림 눌러 바로 공고 보기
**사용자로서**, 알림을 누르면 바로 해당 공고를 보고 싶다, **여러 번 누르지 않고 내용을 확인하기 위해.**
- 관련: FR-11.4, NFR-1.4
- 인수 기준
  - [ ] 새 공고가 1건이면 알림을 눌렀을 때 그 공고의 상세 화면(US-13)이 열린다
  - [ ] 2건 이상이면 피드(US-12)가 열리고, 새 공고에 NEW 배지가 붙어 있다
  - [ ] 알림 → 상세 → 원문 보기가 **2탭 이내**다
  - [ ] 앱이 이미 열려 있어도 해당 화면으로 이동한다

## E4. 공고 보기

### US-12 내게 맞는 공고 목록 보기 (피드)
**사용자로서**, 내가 신청할 수 있는 3기 신도시 공고만 모아 보고 싶다, **자격 안 되는 공고에 시간을 쓰지 않기 위해.**
- 관련: FR-7, FR-5.1~5.3, FR-5.7, FR-2, FR-3, D6, D9
- 인수 기준: 표시 내용
  - [ ] 카드에는 지구, 단지명, 공급유형(쉬운 말 함께), 접수 기간, D-day, NEW 배지, 판정 배지(**자격 충족** / **확인 필요**)가 보인다
  - [ ] 정렬: 접수 중 → 접수 예정, 그 안에서는 추천 점수와 마감 임박 순
  - [ ] 접수가 끝난 공고는 피드에 나오지 않는다
  - [ ] 보여줄 공고가 없으면 "지금은 맞는 공고가 없어요. 새 공고가 나오면 알려 드릴게요"를 보여준다
- 인수 기준: 판정 결과 노출 규칙 (자동 처리의 화면 결과, Q3=C)
  - [ ] 관심 지구에 해당하지 않는 공고는 보이지 않는다
  - [ ] 판정 **"미충족"인 공고는 보이지 않는다** (D9)
  - [ ] 공고의 나이 요건을 **공고 기준일의 만 나이**로 지금 충족하지 못하면 미충족이다. 예: 만 65세 이상 전용 공고는 만 64세면 보이지 않는다 (D6)
  - [ ] 판정에 필요한 프로필 값을 비워 뒀으면(**[잘 모르겠어요]**) 그 공고는 **"확인 필요"**로 보인다 (숨기지 않음)
  - [ ] 공고에서 자격 요건을 정확히 뽑지 못했으면 **"확인 필요"**로 보인다 (숨기지 않음)
  - [ ] 나이 요건이 **본인·배우자 중 누구 기준인지** 공고에서 확실하지 않고 한 분만 충족하면 **"확인 필요"**로 보인다 (놓치지 않기 원칙)
  - [ ] 한 공고 안에 주택형·공급유형이 여러 개면, **하나라도** 충족이거나 확인 필요이면 그 공고를 보여준다
  - [ ] **[P2]** 같은 가구 정보(본인·배우자만 바뀜)를 넣은 두 기기는 같은 공고 목록과 같은 판정 배지를 본다 (단, 나이 요건이 본인 기준으로 명시된 경우는 예외: 열린 이슈 OI-1)

### US-13 공고 상세 보기
**사용자로서**, 공고의 일정과 세대수를 한눈에 보고 원문으로 가고 싶다, **신청 준비를 하기 위해.**
- 관련: FR-8.1, NFR-1.4
- 인수 기준
  - [ ] 일정을 세로 타임라인으로 보여준다: 모집공고일 → 접수 시작 → 접수 마감 → 당첨 발표 → 계약. 오늘 위치가 표시된다
  - [ ] 면적별 공급 세대수를 표로 보여주고, 면적은 평 환산을 함께 쓴다
  - [ ] 화면 맨 위에 **[원문 보기]** 버튼이 크게 있고, 누르면 제공기관의 공고 원문이 열린다
  - [ ] 공급 기관(청약홈/LH/SH/GH)과 공급유형(쉬운 말 함께)을 표시한다
  - [ ] 피드에 없는 공고(미충족·마감)라도 링크로 들어오면 상세는 열리고, 상태(마감 등)를 표시한다

### US-14 내 자격 판정 이유 보기
**사용자로서**, 이 공고에 왜 "자격 충족" 또는 "확인 필요"가 나왔는지 알고 싶다, **스스로 납득하고 무엇을 더 확인할지 알기 위해.**
- 관련: FR-5.5, FR-8.1
- 인수 기준
  - [ ] 조건별로 ✔ 맞음 / ✖ 안 맞음 / ? 확인 필요를 한 줄씩 보여준다 (예: "✔ 나이: 만 65세 이상 → 만 66세", "? 소득: 입력하지 않으셨어요")
  - [ ] "확인 필요" 줄에는 **무엇을 하면 되는지**를 붙인다 (예: "설정에서 소득을 입력하면 정확히 알려 드려요" / "원문의 '신청 자격'을 확인해 주세요")
  - [ ] 주택형·공급유형이 여러 개면 유형별로 판정을 나눠 보여준다
  - [ ] 판정은 "참고용이며 최종 자격은 공고문과 기관 확인이 필요합니다"를 함께 보여준다

### US-15 쉬운 말 AI 요약 읽기
**사용자로서**, 긴 공고문 대신 자격 조건을 쉬운 말로 요약해서 읽고 싶다, **공고문을 다 읽지 않고도 핵심을 알기 위해.**
- 관련: FR-6, FR-4.5, NFR-2.5
- 인수 기준
  - [ ] 상세 화면에 "쉽게 보는 자격 조건"과 "노부부 가구가 볼 점" 요약이 문단 3~5개 이내로 있다
  - [ ] 요약에는 "AI가 공고문을 요약했어요. 정확한 내용은 원문을 확인해 주세요"를 표시한다
  - [ ] 요약이 아직 없거나 실패했으면 요약 자리에 "요약을 준비 중이에요"와 [원문 보기]만 보여준다
  - [ ] 요약은 공고 정보만으로 만들며, **내 정보는 AI에 보내지 않는다** (요약 내용에 내 정보가 섞이지 않음)

### US-16 접수 일정을 캘린더에 넣기
**사용자로서**, 접수 시작일과 마감일을 휴대폰 캘린더에 넣고 싶다, **신청일을 잊지 않기 위해.**
- 관련: FR-8.2
- 인수 기준
  - [ ] 상세 화면에 **[캘린더에 추가]** 버튼이 있다
  - [ ] 누르면 접수 시작·마감 일정이 공고명과 원문 링크를 포함해 휴대폰 캘린더 추가 화면으로 넘어간다 (Android·iPhone 모두)
  - [ ] 접수 일정이 아직 정해지지 않은 공고는 버튼을 숨기거나 "일정이 정해지면 넣을 수 있어요"로 비활성 표시한다

### US-17 관심 공고 저장하고 모아 보기
**사용자로서**, 마음에 드는 공고를 저장해 두고 나중에 다시 보고 싶다, **배우자와 이야기할 때 바로 찾기 위해.**
- 관련: FR-8.3, FR-9
- 인수 기준
  - [ ] 상세 화면과 피드 카드에 큰 **[관심 공고 저장]**(별) 버튼이 있고, 누르면 "저장했어요"를 보여준다
  - [ ] 관심 공고 화면에 저장한 공고가 접수 마감이 가까운 순으로 보인다
  - [ ] 마감된 공고는 "마감" 표시와 함께 남고, [지우기]로 뺄 수 있다
  - [ ] 관심 공고는 이 기기에만 저장된다 (**[P2]** 어머니·아버지 기기는 각자)
  - [ ] 저장한 공고가 없으면 "별 버튼을 누르면 여기에 모아 볼 수 있어요"를 보여준다

## E5. 관리

### US-18 내 정보 고치기
**사용자로서**, 입력한 정보를 나중에 바꾸고 싶다, **바뀐 상황(소득, 주택 등)에 맞는 공고를 받기 위해.**
- 관련: FR-10.1, FR-10.2, FR-4.3
- 인수 기준
  - [ ] 설정에서 그룹별(기본·거주·주택·통장·소득자산·관심 지구·선호)로 바로 들어가 고칠 수 있다
  - [ ] [처음부터 다시 입력하기]로 마법사를 다시 할 수 있다
  - [ ] 고친 뒤 저장하면 기기와 서버에 반영되고(US-08과 같은 실패 처리), 피드 판정이 **바로** 새 정보로 바뀐다
  - [ ] 다음 알림부터 새 정보로 판정한다

### US-19 쉬운 모드로 바꾸기
**사용자로서**, 글씨와 버튼을 더 크게 보고 싶다, **눈이 덜 피로하고 잘못 누르지 않기 위해.**
- 관련: FR-10.4, NFR-1.1, D18
- 인수 기준
  - [ ] 처음에는 **일반 모드**다
  - [ ] 설정에 "일반 / 쉬운 모드" 선택이 있고, 고르는 즉시 미리보기처럼 화면이 바뀐다
  - [ ] 쉬운 모드는 글씨·버튼이 약 1.25배 이상 커지고, **보여주는 정보는 일반 모드와 같다**
  - [ ] 쉬운 모드에서도 가로 스크롤 없이 화면에 맞게 줄바꿈된다
  - [ ] 선택한 모드는 앱을 다시 열어도 유지된다

### US-20 내 정보 모두 지우기
**사용자로서**, 내가 입력한 정보를 모두 지우고 싶다, **앱을 그만 쓰거나 처음부터 다시 하기 위해.**
- 관련: FR-4.4, FR-10.5, NFR-2
- 인수 기준
  - [ ] 설정 맨 아래에 [내 정보 모두 지우기]가 있다 (실수로 누르기 어려운 위치)
  - [ ] 누르면 "입력한 정보, 관심 공고, 알림 설정이 모두 지워집니다"를 보여주고 한 번 더 확인한다
  - [ ] 확인하면 **기기와 서버**의 프로필·알림 구독을 모두 지우고, 이 기기로는 더 이상 알림이 가지 않는다
  - [ ] 지운 뒤에는 처음 실행 화면(US-02)으로 돌아간다
  - [ ] **[P2]** 한 기기에서 지워도 다른 기기(배우자 기기)의 정보는 그대로다

## INVEST 점검

| 기준 | 결과 |
|---|---|
| Independent | 각 스토리는 단독으로 시연 가능. 단, US-12·US-10은 판정 엔진(FR-5)에, US-10·US-11은 US-03에 의존 → Units Generation에서 순서 반영 |
| Negotiable | 인수 기준은 결과 중심이고 구현 방법(라이브러리·테이블 구조)은 정하지 않음 |
| Valuable | 모든 스토리가 P1·P2의 목표(놓치지 않기, 혼자 이해하기)에 연결됨 |
| Estimable | 기능 하나 크기(Q5=B), 경계 사례는 인수 기준으로 명시 |
| Small | 가장 큰 US-12도 화면 1개 + 노출 규칙. 판정 규칙 상세는 Functional Design으로 분리 |
| Testable | 모든 인수 기준이 체크리스트 형태로 E2E·단위 테스트 항목으로 옮길 수 있음 |

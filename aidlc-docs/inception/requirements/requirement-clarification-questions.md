## 충돌 1: 정밀 판정 + 정확한 금액 + 로그인 없음 + 서버 알림

다음 답변들이 함께 성립하기 어렵습니다.

- **Q7=A** 소득·자산까지 넣어 정밀하게 자격 판정
- **Q8=B** 소득·자산을 정확한 금액으로 입력
- **Q10=A** 프로필은 기기(localStorage)에만 저장하고, 서버에는 "푸시 매칭용 최소 조건"만 device_id로 저장
- **Q14=B** 서버가 하루 1회 요약 알림 발송

서버가 알림을 보낼 때 **"자격이 되는 공고만" 세려면 서버에도 소득·자산 정보가 있어야** 합니다.
그런데 Q10=A는 서버에 최소 조건만 둔다고 했고, 보안 확장 규칙은 적용하지 않기로 했습니다(보안=B).
어떤 정보를 서버에 둘지 정해야 합니다.

### 추가 질문 1
알림에 쓸 자격 판정은 어디서, 어떤 정보로 할까요?

A) 서버에는 **관심 지구·공급유형·나이(생년월일) 같은 비금융 조건만** 저장합니다. 알림은 이 조건으로 거른 "새 공고 N건"으로 보내고, 소득·자산까지 넣은 정밀 판정은 앱을 열었을 때 **기기 안에서만** 합니다. (알림 숫자에는 소득 미충족 공고가 섞일 수 있음)

B) 정확한 소득·자산까지 **서버에 저장**해서 알림도 정밀 판정 결과로 보냅니다. 보안 확장 규칙은 끄더라도 최소한의 보호(전송 암호화, RLS, 해당 컬럼 암호화)는 적용합니다.

C) 위 B와 같지만, 서버에는 정확한 금액 대신 **기준 구간(예: 도시근로자 월평균소득 70%/100%/120% 이하)만** 저장합니다. 정확한 금액은 기기에만 둡니다.

X) 기타 (아래 [Answer]: 태그 뒤에 설명해 주세요)

[Answer]: B

## 모호 1: 자격이 안 되는 공고를 피드에 보여줄지

- **Q5=B** 현재 나이로 "지금 신청 가능"한 공고만 보여주고, 65세 이상 전용 공고는 숨김
- **Q7=A** 공고마다 "자격 충족 / 미충족 / 확인 필요"로 표시

Q5에서 나이 때문에 안 되는 공고는 숨기기로 했는데, **나이 말고 다른 이유(소득·자산·무주택 기간·청약통장 등)로 안 되는 공고**를 어떻게 할지가 정해지지 않았습니다.
SPEC §7의 "곧 가능" 탭은 Q5=B에 따라 빼겠습니다.

### 추가 질문 2

B) 피드 아래쪽 "참고" 영역에 회색으로 보여주고, 어떤 조건이 안 맞는지 한 줄로 알려 줍니다.

C) 기본은 숨기고, 설정에서 "자격 안 되는 공고도 보기"를 켤 수 있게 합니다.

X) 기타 (아래 [Answer]: 태그 뒤에 설명해 주세요)

## 모호 3: 일반 모드 / 쉬운 모드의 차이

**Q16=C**(일반 모드와 "쉬운 모드" 전환)를 고르셨고, **Q11=B**로 부모님이 직접 입력합니다.

### 추가 질문 4
쉬운 모드를 어떻게 구성할까요?

A) **쉬운 모드가 기본**입니다. 큰 글씨, 공고 카드에 핵심 정보만(지구·공급유형·접수기간·D-day). 일반 모드에서는 상세 정보와 필터가 보입니다.

B) **일반 모드가 기본**이고, 쉬운 모드는 글씨 크기와 버튼 크기만 키운 버전입니다. 정보량은 같습니다.

C) 처음 실행할 때 "어떤 화면이 편하세요?"를 물어서 모드를 고르게 합니다. 설정에서 언제든 바꿀 수 있습니다.

X) 기타 (아래 [Answer]: 태그 뒤에 설명해 주세요)

[Answer]: B

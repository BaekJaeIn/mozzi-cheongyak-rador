# 변경 요청 2 — 요구사항 질문

> 요청 (2026-10-17): ① 청약통장이 아빠에게만 있어 엄마·아빠 휴대폰의 공고가 달라지는 문제 해결 ② 3기 신도시 밖 공고도 수집하고, 사용자가 고른 지역의 공고만 보여 주기 ③ 이미 설치한 부모님이 새로 생긴 항목을 입력하도록 업데이트 안내
>
> 각 질문의 `[Answer]:` 뒤에 알파벳을 적어 주세요. 모두 추천대로 하려면 "모두 추천대로"라고 말씀해 주셔도 됩니다.

## 지금 구조 (참고)

- **휴대폰마다 내 정보를 따로 저장**하고 따로 판정한다. 본인은 "이 휴대폰을 쓰는 분"이다.
- 판정 항목 중 **나이·소득·자산·세대주는 이미 부부(가구) 기준**이다. **청약통장만 "이 휴대폰 주인" 기준**이라, 엄마 휴대폰에 "통장 없음"을 넣으면 통장 조건이 있는 주택형은 "신청 어려움"으로 숨겨진다. 그래서 두 휴대폰의 피드가 달라진다.
- 수집은 청약홈·LH·GH에서 하고, **6개 3기 신도시 지구에 맞지 않는 공고는 저장하지 않는다** (FR-2.4).
- 관심 지역은 6개 지구 중에서만 고른다.

## Question 1 — 청약통장을 누구 기준으로 볼까요?

A) **부부 기준으로 바꾼다.** 질문을 "부부 중 청약통장이 있는 분이 있나요? → 누구 명의인가요? (나 / 배우자)"로 바꾸고, 판정은 통장을 가진 분의 정보로 한다. 엄마 휴대폰에서 "배우자 명의 있음"으로 넣으면 아빠 휴대폰과 같은 공고가 보인다. 상세 화면 통장 조건에는 "신청은 통장을 가진 분(배우자) 명의로 하세요"를 덧붙인다 **(추천 — 판정 규칙이 다른 항목과 같아지고, 휴대폰은 지금처럼 따로 써도 된다)**

B) 두 휴대폰을 **가족으로 연결**한다(가족 코드 입력). 한 휴대폰에서 고친 내 정보가 다른 휴대폰에도 반영된다. 서버 구조와 개인정보 범위가 크게 바뀐다

C) 청약통장 조건은 **판정에서 빼고** 상세 화면에 안내만 한다(통장 때문에 숨겨지는 공고가 없어짐)

## Question 3 — 관심 지역은 어떻게 고르게 할까요?

A) **3기 신도시 지구 6개 + 시·군·구 여러 개.** 위쪽에 "3기 신도시" 6개 지구를 그대로 두고, 아래에서 시·도 → 시·군·구(예: 서울 송파구, 경기 성남시)를 여러 개 고른다. 피드에는 고른 지구 또는 고른 시·군·구의 공고만 나온다 **(추천)**

B) **시·도 단위만** 고른다 (예: 경기 전체). 지구 선택은 없어진다

C) 지구 목록만 늘린다 (2기 신도시 등 지구를 추가하고 그중에서 고른다)

X) Other (please describe after [Answer]: tag below)

[Answer]: A

B) SH와 iH(인천도시공사) 모두 추가

C) 소스는 그대로 (청약홈·LH·GH). 이 세 곳에 나오는 수도권 공고만 모은다

> 요청 (2026-10-25): 신혼부부 가구(부천 거주, 관심 지역 3기 신도시 부천대장·광명시흥 + 과천·광명·군포·부천·안양·의왕)에 대상·지역이 맞지 않는 공고 9건이 보인다. 공고 상세에서 뒤로 버튼을 누르면 앱이 바로 닫힌다.

## 먼저 정리한 것 (질문 아님) — 운영 DB 확인 결과

### 원인 1. 지역: "경기"까지만 확인된 공고를 경기의 모든 관심 시·군·구에 맞는 것으로 본다

변경 2에서 "시도까지만 확인된 공고는 놓치지 않게 그 시도의 관심 시·군·구에 넣는다"(BR-U2-C11)로 정했다. 문제 공고는 모두 지역이 `경기(시·군·구 없음)`로 저장돼 있다.

| 공고 | 왜 시·군·구를 못 찾았나 |
|---|---|
| 아크메르 동탄 95·99 | 주소가 "경기도 **화성특례시** 동탄구…" — 목록에는 "화성시"만 있어 못 맞춤 (**코드 버그**) |
| 시흥거모 S-1 (LH), 시흥하중 A1 (LH), 구리갈매 S1 (LH) | LH는 주소 칸에 "경기도 + 제목"만 준다. 제목의 "시흥거모"·"구리갈매"에서 시·군을 찾지 않는다 |
| 연천BIX, 창업특화주택 (GH), 경기남부 매입임대 (LH) | 주소가 "경기도"뿐. 공고문 PDF를 AI가 읽어야 알 수 있다 |

### 원인 2. 공고문 AI 분석이 거의 다 실패한다

공고 50건 중 분석 완료 1, **실패 17**, 대기 32. 실패하면 공급 위치(시·군·구)와 공급유형·대상을 공고문에서 못 채워 제목만으로 판정한다. 실패 이유는 공고마다 기록되지 않아 함수 로그를 봐야 한다 (공고문 PDF가 있는 GH 공고도 실패).

### 원인 3. 대상: 분류 못 한 공고는 "확인 필요"로 보인다

| 공고 | 제목으로 정한 공급유형 | 신혼 가구 판정 |
|---|---|---|
| 연천BIX 경기행복주택 기업체 **기숙사** | "행복주택"이 있어 `행복주택 — 어르신 몫` | 신혼부부 몫 임대로 보고 "확인 필요" |
| 경기남부 2026년 일반 **매입임대** | 분류 못 함 (`other`) | 일반공급으로 보고 "확인 필요" |
| 경기도형 **창업특화주택** | 분류 못 함 (`other`) | 일반공급으로 보고 "확인 필요" |

"확인 필요"는 놓치지 않으려고 피드에 보인다(노출 조건 K5). 그래서 기숙사·창업자·취약계층 대상 공고도 보인다.

### 원인 4. 뒤로 버튼

"상세 → 목록 → 안내 → 두 번째에 종료" 규칙은 이미 있다(2026-10-17, 2초, "뒤로 버튼을 한 번 더 누르면 종료돼요"). 휴대폰에서 상세의 뒤로 버튼이 이 처리를 거치지 않고 앱을 닫는다. Android Chrome의 CloseWatcher만 쓰고 방문 기록 지킴이를 함께 두지 않는 경로가 의심된다 — 코드 단계에서 휴대폰으로 재현해 고친다.

### 이번에 그대로 고치는 것 (결정 필요 없음)

- "화성특례시"처럼 이름이 바뀐 시(특례시 등)를 목록 값으로 맞춘다
- LH·GH 제목·주소에서 시·군 이름("시흥거모" → 시흥시, "구리갈매" → 구리시, "연천" → 연천군)을 찾는다
- AI 분석 실패 원인을 찾아 고치고, 실패 이유를 공고별로 남긴다
- 뒤로 버튼: 상세 → 들어온 목록, 맞춤 공고에서 "**종료하시려면 뒤로가기 버튼을 한번 더 클릭해주세요.**" 안내, **3초** 안에 한 번 더 누르면 종료

### 함께 발견한 것 (이번 범위 밖, 알림만)

- 매시 정각 알림 발송 호출이 "Vault 값 없음: dispatch_url 또는 cron_secret"으로 멈춰 있다 → **새 공고 알림이 나가지 않는다**. U6 운영 설정(setup-guide-u6 ⑤⑥)의 남은 일

## Question 1 — 시·군·구를 끝내 모르는 공고("경기"까지만)는 어떻게 할까요?

B) 지금처럼 보이되 피드 맨 아래로 내리고 카드에 "위치 확인 필요"를 붙인다

C) 피드 아래에 "지역을 확인하지 못한 공고 N건" 접힌 묶음으로 따로 둔다

X) Other (please describe after [Answer]: tag below)

[Answer]: X — 제목을 분석해서 맞는지 확인해줘 → (고침) "공고상세까지 봐서 내가 원하는 지역이 있는지 봐줘". 제목·주소·원문 상세(본문·첨부 이름·주택 목록)·공고문(AI)을 다 봐도 시·군을 못 찾으면 숨김 (추가 질문 답)

## Question 2 — 대상이 정해진 공고(기숙사·창업·청년·어르신·장애인·수급자 등)는 어떻게 할까요?

C) 숨기지 않고 카드에 "대상: 창업자" 처럼 대상을 크게 보여 준다

# 모찌네 청약 알리미 — 스토리 ↔ Unit 매핑

> 주 Unit = 그 스토리의 인수 기준을 최종적으로 만족시키는(화면·API를 만드는) Unit.
> 기여 Unit = 주 Unit이 쓰는 데이터·규칙·인프라를 제공하는 Unit.
